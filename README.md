# Movies_Randomizer

A Python script that helps you pick a random movie based on your preferences.Filters movies from a CSV file by duration, genre, year, and director, then shows a few random options.

## Features
- Filter by time, genre, year or director
- Randomly selects up to 3 movies
- Uses **pandas** and **pyinputplus**
- Reads data from movies.csv

This was a **group assignment** developed collaboratively. The **README** was written later by **AmyPap** to document and explain the project clearly.
